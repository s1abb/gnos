Conditional
(Event Node)

Send agents to different exits based on various conditions

Name
The name field defines the identifier for the event node. The compliant form of this name is used to bind the event node object to the simulation scope.

Node names can only contain letters, numbers and spaces. Additionally if a node name starts with a number it must have an underscore prepended, this is the only valid use of an underscore in a node name.

Parameters
Use Probability
Use probability to determine agent's exit.

Bound name: Use_Probability
Input type: Boolean
Required: True
// Default value
return false;
Exit 1 Probability
The probability (0-100%) that the agent will leave through Exit 1. Otherwise, it will leave through the Final Exit.

Bound name: Exit_1_Probability
Input type: Number
Required: True
Boolean dependencies:
Use_Probability == true
Number Of Exits
Number of potential exits agent can be sent to.

Bound name: Number_Of_Exits
Input type: Enum
Required: True
Enum Values:
"2"
"3"
"4"
"5"
"6"
Boolean dependencies:
Use_Probability == false
// Default value
return "2";
