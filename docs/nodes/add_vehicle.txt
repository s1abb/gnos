Add Vehicle
(Event Node)

Add a vehicle to an agent

Name
The name field defines the identifier for the event node. The compliant form of this name is used to bind the event node object to the simulation scope.

Node names can only contain letters, numbers and spaces. Additionally if a node name starts with a number it must have an underscore prepended, this is the only valid use of an underscore in a node name.

Parameters
Vehicle Type
Determines the physics model used by the vehicle added to the agent:

Rail: Full rail physics with mass, multiple locomotives, and carriages.
Road: Full road physics considering vehicle weight.
No Physics (Full Interaction): Simplified acceleration, no physics, but full interaction with other vehicles.
No Physics (Limited Interaction): Most performant, simplified acceleration, no physics, limited vehicle interaction.
Bound name: Vehicle_Type
Input type: Enum
Required: True
Enum Values:
"Rail"
"Road"
"No Physics (Full Interaction)"
"No Physics (Limited Interaction)"
// Default value
return "Rail";
