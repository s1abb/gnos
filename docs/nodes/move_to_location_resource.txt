Move to Location Resource
(Event Node)

Move to a location requested from a specific Location Resources node.

Name
The name field defines the identifier for the event node. The compliant form of this name is used to bind the event node object to the simulation scope.

Node names can only contain letters, numbers and spaces. Additionally if a node name starts with a number it must have an underscore prepended, this is the only valid use of an underscore in a node name.

Parameters
Location Resource
Target Location Resources node.

Bound name: Location_Resource
Input type: Any
Required: True
Autocomplete set: Event Nodes
Passing Locations
Optional list of passing locations.

Bound name: Passing_Locations
Input type: List
Required: False
Rows
Location, (Required)

Future Locations
Optional list of future location used for deadlock avoidance.

Bound name: Future_Locations
Input type: List
Required: False
Rows
Location, (Required)

Exits
exit
Exit once vehicle has navigated to the requested location.

Bound name: exit
