Engine (Sectional Runtime)
The sectional runtime variant of the Engine bound object is a unique engine type that is intended use real world sectional runtime data as an input. The input data specifies the time it takes the vehicle to pass through a section. Sectional Runtime Engines are created when calling the set_sectional_runtime() method of Rail Vehicles.

Sectional Runtime Engines uses the runtime data set when creating the engine to specify the duration the vehicle should take to travel through sections. If a section is not present in the input runtime data then the engine will fallback to a simple speed/velocity estimates.

Bound Values
sectional_times_data SectionalTimesData [get, set]

Get and set the sectional times data of the sectional runtime engine. Can also be set with a list or maptype. same as set_sectional_runtime.

SectionalTimesData
The SectionalTimesData is the underlying storage object of the sectional runtime engine.
