VehicleType
The Vehicle Type bound object represents the configuration of a rail locomotive and is used for initialising new Vehicle Component bound objects. It is created using the Rail Vehicle simulation setup node.

The Add Vehicle event node using the "Rail" vehicle type setting uses the Vehicle Type bound object to add rail locomotives to an agent's vehicle. Once a locomotive has been added to an agent it uses the Vehicle Component bound object.

See the Rail Vehicle simulation setup node for more information.

Bound Values
The vehicle type bound object implements all the bound values from Component Type (Base).
