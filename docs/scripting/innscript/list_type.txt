Lists
Lists store a collection of values, each value can be of any type.

my_list = [];

// Add a string
my_list.push("My String");

// Add a number
my_list.push(123);

// my_list now equals ["My String", 123]
Syntax
[]

[el0, el1]

[el0, el1, /* ..., */ elN]
Parameters
el (Optional)

Any number of expressions to be used as the list's elements.

Iteration
Lists can be iterated on using for loops.

The code below will output 3 entires to the simulation DEBUG logs ("first", "second", 3).

my_list = ["first", "second", 3];

// Loop elements in the list
for el in my_list
{
    simulation.log(el);
}
Indexing
List elements can be accessed and set using a zero-based index.

my_list = ["first", "second", 3];

my_list[0]; // "first"
my_list[1]; // "second"
my_list[2]; // 3

// Set element at index 2 to "three"
my_list[2] = "three";
Concatenation
Lists can be combined using the + operator. A new list is created that combines the values of both lists.

list1 = [1,2,3,4];
list2 = [5,6,7,8];

list3 = list1 + list2; // [1,2,3,4,5,6,7,8]
Truthiness
Empty lists are falsy. Non-empty lists are truthy.

String
When converting a list to a string:

each of the elements in the list will be converted to a string
each element will be separated by a comma
the whole string will be enclosed in square braces [ ]
some_variable = "value";

my_list = ["string", 123, DateTime("2025-01-15 10:00:00"), some_variable];

stringify(my_list); // "[string, 123, DateTime("2025-01-15 10:00:00"), value]"
List Methods
push(TypeValue)

Argument 1: A value of any type to append to the end of the list.

insert(NumberType, TypeValue)

Argument 1: Index in the list to insert the new value.

Argument 2: A value of any type to insert into the list at the specified index.

Inserts an element at a specific index in the list, increasing the index of all elements starting from the specified index by 1.

copy() ListType

Returns: a copy of the list.

len() NumberType

Returns: the number of elements in the list.

clear()

Sets the list to a new empty list.

index_of(TypeValue) NumberType

Argument 1: Element to find the index of in the list.

Returns: The first index of the element in the list if it exists, otherwise -1.

contains(TypeValue) BoolType

Argument 1: Element to search for in the list.

Returns: true if the element exists otherwise false.

remove(TypeValue)

Argument 1: The element to remove from the list.

Will only remove the first occurrence of the element from the list. If the element does not exist in the list nothing will be changed.

pop(NumberType) TypeValue

Argument 1: The index of the element to retrieve from the list.

Returns: The element at the specified index in the list.

The element at the specified index will be removed from the list.

slice(NumberType, NumberType) ListType

Argument 1: Start index or null. The start index is inclusive.

Argument 2: End index or null. The end index is exclusive.

Returns: A new list made up of elements from the start index to the end index.

If the start index is null, a start index of 0 will be used. If the end index is null, an end index of list.len() will be used.

sort() ListType

Returns: A new list with the elements sorted in ascending order, if the types are incomparable an error will be raised.

sort(FunctionType) ListType

Argument 1: Function expecting two values input, should return 1 if a > b, -1 if a < b and 0 if a == b.

Returns: A new list with the elements sorted by the sort function.

filter(FunctionType) ListType

Argument 1: Function expecting a single value input, will return value thats truthyness is used to filter.

Returns: A new list with the elements filtered by the truthy value of the function return.

find(FunctionType) ListType

Argument 1: Function expecting a single value input, will return value thats truthyness is used to find an element.

Returns: The first element that that returns a truthy value when passed into the function provided or null if no elements return a truthy value.

to_reversed() ListType

Returns: A new list with the order of the elements reversed.

shuffle() ListType

Returns: The list after being shuffled.

Randomly shuffles the list and returns a reference to the same list after it has been shuffled.

get_random() TypeValue

Returns: A random element from the list or null if the list is empty.

repeat(NumberType) ListType

Argument 1: Number of times to repeat list. Must be a positive integer.

Returns: A new list that repeats the original list the given number of times.

Creates a new list that repeats the original list the given number of times. e.g. [1, 2, 3].repeat(2); will create a new list equal to [1, 2, 3, 1, 2, 3].
