Date
The Date type stores a UTC date and time value.

Syntax
The standard library contains a function Date() which can be used to create a new Date using a string in the format YYYY-MM-DD.

// Create a Date type that represents Wed Jan 15 2025
Date("2025-01-15");
Add/Remove Delta Time
You can add or subtract a DeltaTime type with a Date type to increase or decrease the value of the Date. The resulting value is a Date type. Any time values remaining after the arithmetic will be truncated, leaving only the date value. When undergoing arithmetic, the date is assumed to be a datetime of the date at midnight (the start of the date).

date = Date("2025-01-16");
delta = DeltaTime("24h");

simulation.log(date + delta); // 2025-01-17
simulation.log(date - delta); // 2025-01-15
Add Time
A time value can be added to a date to get a datetime value.

date = Date("2025-01-16");
time = Time("12:30:00");

datetime = date + time; // 2025-01-16 12:30:00
Delta Time
You can get the duration between two Date types by subtracting the one from the other. The result returned is a DeltaTime type.

date = Date("2025-01-16");
other = Date("2025-01-15");

simulation.log(date - other); // 24h
Truthiness
All Date types are truthy.

Comparison
Date types can be compared to other Date types.

date = Date("2025-01-15");
other = Date("2025-01-20");

// Does date equal other
date == other; // false

// Does date occur before other
date < other; // true

// Does date occur after other
date > other; // false
Stringify
The string representation of a Date type is in the format YYYY-MM-DD.

Methods
year() NumberType

Returns: The 4-digit year in which the date occurs

month() NumberType

Returns: The month in which date occurs [1-12]

day() NumberType

Returns: The day of the month in which date occurs [1-31]
